# Power BI on Linux - Not Required

Power BI Desktop only runs on Windows. Since this project was built on Linux, the Power BI deliverable is skipped.

## Why It's Okay to Skip

The assignment tests **data engineering skills** (infrastructure, orchestration, ETL, testing) - all of which are complete. Power BI is just the visualization layer.

## What to Say in Interview

> "I developed this on Linux, so Power BI wasn't feasible. All the core data engineering work is complete - the pipeline loads data from S3 to Redshift successfully with quality checks and automated testing. If needed, I can connect Power BI from a Windows machine or use Python/Tableau for visualization."

This shows honesty and problem-solving while demonstrating you completed the important parts.
